# Grid

CSS grid with responsive equal-width columns
(`repeat(columns, minmax(0, 1fr))`) and token gaps. Deliberately small: for
named areas, column spans, or auto-fill tracks, use `className`/`style` —
those are full CSS grid features this primitive does not wrap.

## Import

```tsx
import { Grid } from '@vegam-ui/ui';
```

## Accessibility

A generic `<div>` with no implicit role and no interaction. Layout only —
pass `role`/`aria-*` through when the collection has meaning (the test suite
shows `role="list"` passing through).

## Theming

- `gap` is themeable via
  `ThemeProvider componentDefaults={{ Grid: { gap: 4 } }}`.
- `gridClasses.root` is the class override surface.
