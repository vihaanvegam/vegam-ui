# Divider

A themed rule between content regions, drawn at the hairline width with the
semantic divider colors. Not for decoration inside a component's own chrome —
components draw their internal borders themselves.

## Import

```tsx
import { Divider } from '@vegam-ui/ui';
```

## Accessibility

Horizontal renders a native `<hr>` (implicit `separator` role); vertical
renders `role="separator"` with `aria-orientation="vertical"`, since `<hr>`
is semantically horizontal-only. Screen readers announce both as separators —
add `aria-hidden` when the rule is purely decorative. Not interactive, not
focusable.

## Theming

- `tone` is themeable via
  `ThemeProvider componentDefaults={{ Divider: { tone: 'subtle' } }}`.
- `dividerClasses` exports root, orientation, and tone classes.
