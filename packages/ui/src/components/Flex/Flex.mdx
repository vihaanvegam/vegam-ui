# Flex

The full flexbox container surface with responsive props. **Stack is the
simple sibling** — one axis, one gap, class-per-step; keep using it for plain
vertical/horizontal stacks. Flex is for everything else: wrapping, reversed
axes, per-breakpoint direction changes, distribution control, and styling a
flex _item_ (`grow`/`shrink`/`basis`). Flex has no padding/margin surface —
compose with Box for spacing.

## Import

```tsx
import { Flex } from '@vegam-ui/ui';
```

## Accessibility

A generic `<div>` with no implicit role and no interaction. Layout only —
pass `role`/`aria-*` through when the group has meaning.

## Theming

- `gap` is themeable via
  `ThemeProvider componentDefaults={{ Flex: { gap: 4 } }}`.
- `flexClasses.root` is the class override surface.
